# Completed Amended Study Summaries

These files are copied, without content changes, from the completed remote
`support-v1a` campaign at revision
`e5f7e79a3447616909274ba078b27e3486ddf73b`. See
[the study record](../../STUDY-STATUS.md) and
[the amendment](../../../studies/support-v1a/README.md).

The campaign contains 380,000 construction observations, 570,000 held-out
validation observations, and 19,000 port observations. Three reference engine
errors remain in the fixed-budget denominators; no port engine errors were
recorded. The amended outcome policy was adopted after the first reference
failure. Neither an unchanged prospective experiment nor support equality is
claimed.

`analysis.json` contains per-input counts, frozen heads, held-out and port
checks, prefix comparisons, nominal confidence limits, frequency comparisons,
error reproducer records, and available execution costs. `RESULTS.md` is the
generated summary. `manifest.json`, `protocol.json`, `COMPLETE.json`,
`analysis-status.json`, and `parent-import.json` retain scientific provenance
and hash inventories.

This directory is a result-summary export. The separately audited
[full raw-data release](../../../studies/support-v1a/data/README.md) now contains
the checksummed per-run files, original attempts, diagnostic preflight, pilot,
and failed parent study, with instructions for self-contained reanalysis.
No original Metacat source, private local configuration, network addresses,
or Docker image identifiers are included.

The existing manuscript PDF and its analysis supplement still describe the
historical study; these new results require a substantive manuscript revision
and updated bundles before submission. Merely copying these summaries does
not update the older manuscript artifacts.
