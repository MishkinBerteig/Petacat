# Anonymous Review Supplement

**Large References, Small Checks: Oracle-Guided Porting of a Stochastic Learning System**

This single attachment contains two complementary, self-contained bundles:

- `support-set-oracles-experiments.zip`: saved study evidence, frozen source,
  Metacat reconstruction patches, and analysis. Extract it into a new directory
  and start with its `README.md`. Run `python3 verify.py` from that directory
  for saved-data verification; `REPRODUCE.md` documents dependencies and the
  optional full single-run reanalysis. Neither verification path runs an engine.
- `support-set-oracles-tmlr-source.zip`: manuscript LaTeX, references, generated
  tables, and official style files. Extract it into a separate directory and
  follow `SOURCE-README.md` to rebuild the manuscript PDF.

`UPLOAD-MANIFEST.json` records the exact size and SHA-256 of these bundles and
this README. The inner archives are included unchanged. The experimental bundle
already includes the historical arithmetic evidence; a third analysis-only
archive is unnecessary.

No original upstream Metacat source, runtime binary, identifying author details,
or private submission-form responses are added. The experimental bundle explains
its evidence exclusions and anonymity limits. Reconstruction obtains the linked
upstream tarball separately, preserving the original licensing boundary.
