# Anonymous Supplement

This attachment supports **Large References, Fast Checks: Oracle-Guided
Porting of a Stochastic Learning System**.

It contains:

- `support-set-oracles-12-page-source.zip`: the current manuscript's Markdown,
  generated LaTeX, bibliography, audited tables, official TMLR style, and
  rebuilding instructions. This source builds the PDF with at most 12 pages
  of main content, followed by references and appendices.
- `support-set-oracles-experiments.zip`: the scientific records, saved-data
  audits, frozen port source, tests, and Metacat reconstruction patches.
  Its README explains dependencies and reproduction. Original upstream
  Metacat source and runtime binaries are not redistributed.
- `UPLOAD-MANIFEST.json`: hashes and sizes of the attachment's components.

The source bundle is sufficient to rebuild the manuscript, not to rerun
the campaigns. The experimental bundle's `python3 verify.py` checks saved
results and source hashes without running either analogy engine. Follow
its README for the limits of historical reproduction and the distinction
between saved observations and unavailable internal execution states.

This attachment contains no author identity or private operational details.
The manuscript's appendices are already included in the submitted PDF.
