# Anonymous Submission Supplement

**Large References, Fast Checks: Oracle-Guided Porting of a Stochastic
Learning System**

This is the single supplementary attachment accompanying the manuscript.
It contains two self-contained ZIPs and a checksum inventory:

- `support-set-oracles-final-source.zip`: Markdown, generated LaTeX,
  references, twelve data tables, the official TMLR styles, and build
  instructions for the accompanying manuscript.
- `support-set-oracles-experiments.zip`: the historical measurements,
  both versioned studies, frozen source, analysis tools, and Metacat
  reconstruction patches. Start with its README after extraction.
- `UPLOAD-MANIFEST.json`: byte counts and SHA-256 checksums of both
  ZIPs and this README.

The experimental bundle is unchanged and retains an earlier working title
in its documentation. Its saved-data verifier does not
rerun the expensive analogy experiments. The paper's appendices describe
which findings can be reproduced from the public records and which
historical or raw-state evidence is unavailable.

The original upstream Metacat source and runtime binaries are not
redistributed. The experimental bundle provides the upstream link,
patches, reconstruction instructions, and original licence terms.
